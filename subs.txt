# Feature Gating

Whenever a Free user reaches a limit,

DO NOT allow the action.

Instead automatically display the Premium Paywall Modal.

Examples

Trying to add a 4th Medication

Trying to create a 2nd Appointment

Trying to perform another Daily Check-in

Trying to exceed AI conversation limit

Trying to use AI Health Insights

Trying to Export Reports

Trying to add additional Family Members

Any Pro-only feature

Every premium feature should automatically trigger the Premium Paywall Modal.

---

# Backend Enforcement

Subscription limits MUST NOT rely only on frontend checks.

The backend/API must verify the user's subscription before allowing any premium action.

Even if someone modifies frontend code or manually sends API requests, Free plan limits must still be enforced.

Use the subscription status stored in Supabase after Paddle webhook confirmation.

Never trust the frontend.
